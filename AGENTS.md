# Project Color Palette Guidelines

Always use the official project color palette for all UI components, pages, styles, and future design changes:

- **Primary Color**: `#0050CB` (Brand royal blue for primary buttons, active links, main CTAs, emphasis)
- **Light Blue**: `#E5EEFF` (Soft background tints, badges, light card surfaces, hover states)
- **Orange**: `#FF690C` (Accents, notifications, warning badges, highlights, secondary CTAs)
- **Dark Blue**: `#000E28` (Dark text, deep headings, dark card/footer backgrounds)
- **White**: `#FFFFFF` (Card surfaces, clean backgrounds, button text, crisp borders)

### Tailwind Utility Aliases
- Primary: `bg-primary` / `text-primary` / `border-primary` / `bg-[#0050CB]` / `text-[#0050CB]`
- Light Blue: `bg-light-blue` / `text-light-blue` / `bg-[#E5EEFF]` / `text-[#E5EEFF]`
- Orange: `bg-orange` / `text-orange` / `bg-[#FF690C]` / `text-[#FF690C]`
- Dark Blue: `bg-dark-blue` / `text-dark-blue` / `bg-[#000E28]` / `text-[#000E28]`
- White: `bg-white` / `text-white` / `#FFFFFF`
